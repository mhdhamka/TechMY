# About

`TechMY` is a simple, practical resource hub and digital library for learning software engineering, AI, DevOps, data, and cybersecurity in a Malaysian context.

## Why this site exists

- To reduce information overload for beginners entering the tech industry.
- To provide relevant, local examples and ecosystem resources tailored for Malaysia.
- To focus on practical outcomes: cleaner code, robust architectures, and production-ready skills.

## Who this is for

- Students and fresh graduates starting a tech or software engineering career.
- Working professionals transitioning into engineering and IT roles.
- Current developers who want a quick, no-noise technical reference page.

## Analytics

This site uses privacy-friendly analytics to track engagement and improve the resource collection.

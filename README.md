## Overview

**TechMY** is a community-driven, open-source tech curriculum and career resource tailored specifically for the Malaysian tech landscape. Born from curating a personal tech book collection and deeply inspired by structural philosophies like *The Odin Project*, TechMY bridges the gap between global technical standards and regional industry requirements—taking learners from absolute beginners to production-ready developers.

---

## Key Features

* **Curated Learning Paths:** Structured tracks covering Software Engineering, Data Engineering, DevOps & Infrastructure, Cybersecurity, and AI/ML.
* **🇲🇾 Malaysian Tech Ecosystem:** Localized guides on regional hubs, active tech communities, meetups, local hiring markets, and PDPA compliance.
* **Industry Foundations:** Grounded in core engineering literature like *Clean Code*, *The Pragmatic Programmer*, and Google's *Site Reliability Engineering*.
* **High-Performance Documentation:** Built with VitePress for lightning-fast navigation, and seamless local development.

---

## Content Structure

- `docs/software-engineering/` - Core software engineering tracks, clean code principles, code construction, and interview prep.
- `docs/data-engineering/` - Data pipelines, warehousing, and optimized SQL recipes.
- `docs/devops-infrastructure/` - Containerization (Docker), CI/CD workflows, SRE practices, and operations.
- `docs/cybersecurity/` - Core security fundamentals, secure coding standards, and OWASP guides.
- `docs/ai-ml/` - Artificial intelligence, machine learning architectures, and LLM pipelines.
- `docs/system-design/` - Enterprise system design patterns and architecture standards.
- `docs/local-resources/` - Malaysian ecosystem guides, communities, and career paths.
- `docs/tooling/` - Essential tool guides and configuration files.
